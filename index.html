TransitPulse BC: Streaming Transit Lakehouse

A streaming lakehouse on AWS ingesting Metro Vancouver's live transit feed: ~16 million events a day of GTFS-Realtime protobuf, polled every 60 seconds. Built to predict bus arrival delay against a baseline anyone can check, the published schedule. The stream splits at Kinesis into two independent paths: a live path keeping current delay state in DynamoDB (serving features in under 50 ms), and a batch path landing Parquet in an S3 medallion lakehouse, where a nightly Spark job collapses ~25 repeated predictions per arrival into one labelled row (2,021,771 → 79,945) and a five-rule quality gate routes bad days to quarantine instead of crashing the pipeline.

~120 AWS resources, all Terraform. Zero EC2 instances. ~$0.70/day. The platform is verified end to end and ingesting continuously; the XGBoost modelling layer is in progress while training data accumulates. No accuracy numbers claimed until the model has earned them.

CodeIQ: Source Code Knowledge Graph

Built for the HCLTech × UBC AI/ML hackathon: parses a ~100K-line React Native codebase (bluesky-social/social-app) into a queryable knowledge graph of 3,820 entities and 25,000 edges via AST extraction, then layers a ChromaDB semantic index on top. An LLM agent with graph-traversal tools answers plain-English questions about structure and change impact, citing real file paths and code snippets. The whole pipeline (clone → parse → index → chat UI) runs as a one-command, resumable Docker Compose workflow.

Soil Geochemistry Prediction from Satellite & Geophysical Data

UBC MDS capstone with industry partner VRIFY: predicted soil geochemistry for 10 target elements across 3 mining exploration areas from 130+ multi-source raster features per site, to help guide site selection where soil sampling is sparse and expensive. Cut 390 candidate features to a lean 25 via a two-stage elimination (Spearman correlation filtering + Recursive Feature Elimination), and designed a spatially-aware cross-validation scheme (grouped by 2 km tiles) to keep spatial autocorrelation from leaking between train and validation folds.

Built and benchmarked five deep-learning architectures, lightweight CNNs, an Expert CNN framework with per-element candidate selection, U-Net with a ResNet-34 encoder, and the DOFA foundation model, against VRIFY's production RandomForest baseline. The best model reached R² 0.65 versus 0.3 for the baseline, with SHAP analysis confirming predictions were driven by genuine magnetic, gravity, and Sentinel signal rather than spurious positional proxies.
